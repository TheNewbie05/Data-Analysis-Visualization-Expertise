# Data-Analysis-Visualization-Expertise
Author: Vishal Kumbhakar

Location: Jamshedpur, Jharkhand, India

## Technical Stack: Python, Power BI,  DAX

## 🌟 Executive Summary
This repository is a consolidated collection of five major data projects. It demonstrates a full-cycle analytics approach: from data cleaning and exploratory analysis in Python to building high-performance, interactive dashboards in Power BI.

## 📂 Project Directory
## 1. ## 🦠 COVID-19 Global Impact Analysis
Focus: Analyzing the first wave (Jan–Aug 2020) spread and US mortality.

Key Insight: Proved the heavy correlation between age (65+) and specific comorbidities with fatality rates.

Tools: Python (Pandas), Power BI (Global Mapping).


## 2. ## 🎓 Student Performance Analytics
Focus: Evaluating how socio-economic factors and test prep impact grades.

Key Insight: Identified that test preparation completion narrows the performance gap, particularly in literacy subjects.

Tools: Python (Seaborn), Power BI (Educational KPIs).


## 3. 📱 Social Media Viral Trends
Focus: Analyzing engagement across TikTok, Instagram, and YouTube.

Key Insight: Demonstrated that short-form video content (Shorts/Reels) achieves the highest engagement-to-view ratio.

Tools: Python (Feature Engineering), Power BI (Marketing Analytics).


## 4. 🌤️ Weather Forecasting & Patterns
Focus: Analyzing historical weather data to identify trends and seasonal shifts.

Key Insight: Visualized temperature anomalies and precipitation patterns using time-series forecasting techniques.

Tools: Python (Time-series Analysis), Matplotlib, Power BI.



## 5. 🛒 Superstore Market Analysis
Focus: Retail data mining to optimize sales, profit, and shipping efficiency.

Key Insight: Identified high-loss categories and optimized regional sales targets through basket analysis.

Tools: Jupyter notebook(Pyhton), Power BI (Sales Dashboards).
